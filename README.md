# cocoanimated

The character animation system for **Coco**, the parrot mascot of the English-learning travel app.

Everything lives in [`COCO_ANIMATION_SYSTEM/`](COCO_ANIMATION_SYSTEM/README.md): the master
character, the [Rev2D](https://github.com/RevStudio/Rev2D) rig, the animation library, exports and
the web player, with the plan, the character specification and the progress report.
